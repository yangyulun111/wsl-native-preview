# Changelog

All notable changes use semantic versioning.

## 0.2.0 - 2026-08-12

- Bind preview operations to a short-lived Hook-created workspace context.
- Expose only status, batch preparation, and exact mapping release MCP tools.
- Keep the target-build-gated DOS-device alias backend verified by `QueryDosDeviceW`.
- Add SessionStart, Stop, and SessionEnd lifecycle hooks.
- Prefer Codex's writable plugin data directory for runtime state.
- Add a Git marketplace, reproducible bundles, CI validation, and public documentation.
